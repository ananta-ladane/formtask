A full-stack Google Form Clone built using the MERN Stack. Users can create custom forms with different question types, share forms with others, collect responses, and view submitted data.

## Features
### Form Creator
- Create new forms
- Add unlimited questions dynamically
- Multiple question types:
  - Text
  - Email
  - Number
  - Radio Button
  - Checkbox
  - Select Dropdown
- Edit or delete questions

### Form Submission
- Open forms Check form
- Submit responses
- Required field validation
- Store responses in MongoDB

### Response Management
- View all submitted responses
- Store responses with form ID
- Display responses in card format

## Tech Stack

### Frontend

### Backend
